# Bible Accuracy Benchmark — v0.2

**Status:** current · **Generation:** 2026-07 · **Supersedes:** [v0.1](v0.1.md)

v0.2 keeps v0.1's structure — the same three deterministic tracks, the same
Overall Score formula, and multiple translations — and improves how faithfully
the scorer detects quoted scripture. It also aligns all three tracks to one
shared 11-language set. The goal of the changes is singular: **be clear with
models about how to quote, and reliably catch every quote so we score quote
accuracy fairly.**

> **Overall Score** = 100 × (0.50 × Direct Quotation + 0.25 × Scripture in Answers + 0.25 × Hallucination Resistance),
> each track averaged across the languages it covers.

For the full description of the three tracks and scoring, see [v0.1](v0.1.md);
only the differences are described below.

## Changes from v0.1

1. **A system prompt on every test (all tracks).** Each request now carries:
   > *"When you quote text from the Bible, put the quoted words inside double
   > quotation marks and give the reference (book chapter:verse). Quote the
   > wording exactly as it appears in the translation you are citing."*

   It is phrased **conditionally** ("when you quote"), so it does **not** force
   the implicit topical level (L2) to quote — it only standardizes the format
   when a model chooses to quote. This is fairer to the models (we tell them
   exactly what we want) and makes quote detection reliable.

2. **Simple-track prompt reconciled.** v0.1's direct-quote prompt told the model
   to respond "with no reference, no quotation marks" — which fought the new
   system prompt and the detector. v0.2 drops that; it asks only for the verse
   itself with no commentary, and lets the system prompt govern formatting. (The
   direct-quote scorer aligns against the known verse, so quotes/reference in the
   response are simply stripped before scoring.)

3. **Unquoted near-verbatim detection.** The topical and hallucination scorers
   now also catch scripture a model presents **without** quotation marks: each
   sentence outside the quoted spans is checked against the verse text, and a
   **near-verbatim match (≥ 90% character similarity)** is treated as a presented
   quote — accurate at ≥ 98%, a graded misquote between 90% and 98%. Reference
   attribution is applied the same way as for quoted spans (wrong verse →
   misattributed).

   Crucially, anything **below 90%** yields no verdict, so a paraphrase or
   allusion is **never** turned into a misquote — putting words in quotation
   marks remains the signal that earns full scrutiny. The backstop only ever adds
   a confident "this is verbatim verse X" detection; it never manufactures a
   misquote out of ordinary prose.

4. **Benchmark version comes from the codebase.** The eval runner no longer takes
   a `--run-version` flag; the version is the `BENCHMARK_VERSION` constant in the
   code (this file's generation). Bumping the code version defines a new, frozen
   generation; older runs keep their version.

5. **Graded Hallucination Resistance (no longer all-or-nothing).** v0.1 failed a
   model for quoting *anything* when asked for a non-existent reference. But a
   genuinely good answer often says *"that isn't in the Bible"* and then offers a
   real, clearly-cited verse as a helpful alternative — which v0.1 scored the same
   as inventing a fake verse. v0.2 grades the response deterministically:

   - **1.0** — declines entirely; **or** offers only real, correctly-attributed
     scripture **and** deterministically signals the reference isn't in the Bible
     (an "out of range / no such chapter / doesn't exist" phrase, matched per
     language).
   - **0.5** — offers a real, correctly self-referenced verse but never tells the
     user the requested reference doesn't exist.
   - **0.0** — asserts scripture where none exists: invents verse text, pins a
     real verse to the fake reference, or recites real scripture with neither a
     reference nor a warning.

   The failing cases are exactly those where the model implies the phantom
   reference contains scripture — the hallucination the track targets. Detection
   of the "isn't in the Bible" signal is a deterministic per-language phrase match
   (see `dataset/phantom-v1.json` `denial_markers`); non-English marker lists are
   machine-drafted pending native-speaker review.

6. **A Catholic Bible with the deuterocanon.** English adds NABRE, and the sampler
   now draws from its seven deuterocanonical books (Tobit, Judith, Wisdom, Sirach,
   Baruch, 1–2 Maccabees) — sampled only from translations whose canon actually
   includes them.

7. **One shared 11-language set.** v0.1's Direct Quotation track spanned ~28
   languages while Scripture in Answers and Hallucination Resistance covered only
   11, leaving the matrix half-empty (a language with a single-verse score but no
   topical/hallucination score). v0.2 aligns all three tracks to the same 11
   languages — Arabic, Chinese, English, French, German, Hindi, Indonesian,
   Korean, Portuguese, Russian, Spanish — so every covered language has all three
   scores. The other languages' direct-quote prompts remain in the dataset for a
   later round, once their topical and hallucination prompts get native-speaker
   review.

8. **A run either completes cleanly or fails — and silence never scores.** Two
   integrity rules, both aimed at the same failure mode: a broken run that
   produces plausible-looking numbers instead of no numbers.

   - **Any model call that exhausts its retries aborts the whole run**, which is
     left unscored and unpublishable. Previously such failures were recorded
     per-item and the run carried on; because a failed call reaches the scorers
     as "no attempt", it quietly deflated the quote tracks and *inflated*
     hallucination resistance — an empty response reads as "declined to quote".
   - **An empty response scores zero, everywhere** — including the hallucination
     track, where it previously counted as a principled refusal and earned full
     marks. The bar is that the model must either give the quote or say why it
     can't; saying nothing earns nothing. The one exception is mechanical rather
     than semantic: if a reply is empty *because it hit the output-token cap*
     (`finish_reason` = length), that's a truncated measurement, not an answer,
     so it retries and then fails the run.

   Provider content filters are treated as real observations, not errors: Gemini's
   anti-recitation filter blocks verbatim scripture on a small fraction of items,
   which scores zero and is reported as a `no_response` rate rather than silently
   mixed in with misquotes.

## Why it matters

- **Scores hallucination resistance the way a reader would judge it.** Declining
  is good; declining *and* pointing to a real, clearly-cited verse is just as
  good; quietly substituting a real verse without a reference — or inventing one —
  is not. v0.2 separates these instead of lumping them together.
- **Fixes a false pass from v0.1's quote detection.** A non-existent verse
  answered by reciting a *real* verse in plain prose (no quotation marks) was
  scored "declined" in v0.1; v0.2 catches that unquoted substitution and grades it
  on the same ladder.
- **Credits legitimate unquoted quotes** in topical answers that v0.1 missed.
- **Still protects paraphrase**, which the benchmark has always treated as
  legitimate and never penalized.
- **Tests the deuterocanon** for the canons that contain it.

## Unchanged from v0.1
Tracks, weights, the character-level accuracy metric and severity grades, the A×E
topical scoring, the deterministic-only principle, and the scope disclaimer
(accuracy of quoted scripture only, never theology).
