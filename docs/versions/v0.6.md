# v0.6 — Hallucination becomes the same test, inverted

**Released:** 2026-08 · **Changes from:** [v0.5](v0.5.md)

v0.5 gave Direct Quotation one question set asked of every translation.
Hallucination Resistance did not get the same treatment, and the gap was worse
than a design inconsistency: **the dimension measured one reference kind on 11 of
the 18 editions while reporting as four kinds on eighteen.**

## The one idea

Hallucination is the Direct Quotation test with the references inverted. Same
prompt wording, same translation matrix, same drawn-once-then-asked-of-everyone
structure — the only difference is whether the reference exists.

That makes the two dimensions a controlled comparison, and it is what makes a
per-translation hallucination score meaningful: whether a reference is out of
range can depend on the edition's versification, so a per-language figure would
average away the very difference the dimension exists to detect.

## What was wrong

Thinning was applied to the **finished item list**, which is built edition by
edition and kind by kind. A 10% prefix of that list therefore kept only the first
edition of each language and only the first reference kind:

| | v0.5-fast (as shipped) | v0.6-fast |
|---|---|---|
| editions asked | 11 of 18 | **18 of 18** |
| reference kinds | 1 of 4 | **4 of 4** |
| items | 34 | 60 |
| items at full scale | 152 | 352 |

Seven editions — KJV, NLT, NABRE, NRSVUE, Arabic CAV, Portuguese AVM, Russian
SYNOD — carried no hallucination items at all, so their board cell was a credit
with nothing charged against it. Of the 34 items that did run, 33 were
`out_of_range_chapter` and one was `out_of_range_verse`; no run at fast scale ever
asked a non-canonical book or a wrong-canon reference.

The fix is structural, not a patch: `draw_phantom_references()` draws the
reference list **once**, thinning happens there, and only then is the list asked
of each edition. Nothing can drop out of the matrix, because the matrix is
applied after the thinning. `_thin_per_language` is deleted.

Every edition now gets an identical 15-reference core (10 out-of-range chapters,
5 out-of-range verses). Per-cell totals run 16–22 because two kinds vary by
canon, deliberately — see below.

## Non-canonical books are derived, not curated

`fake_refs` was a curated list of six English strings. Every other language got
**none**, because a plausible fake book in one language is a real book in another
("Judas" is the book of Jude in Spanish), and no one had written a safe list for
the other ten.

Non-canonical references are now built from each edition's own localized book
names, by bumping the number on a series that tops out:

| language | edition's real book | reference asked |
|---|---|---|
| eng | 2 Corinthians | 3 Corinthians 1:1 |
| spa | 2 CORINTIOS | 3 CORINTIOS 1:1 |
| por | 2Coríntios | 3Coríntios 1:1 |
| deu | 2. Korinther | 3. Korinther 1:1 |
| kor | 요한3서 | 요한4서 1:1 |
| zho | 约翰三书 | 约翰四书 1:1 |
| hin | 2 कुरिन्थियों | 3 कुरिन्थियों 1:1 |

The bump handles any way a **script** writes the number — Latin digits,
Arabic-Indic (`٢`→`٣`), Devanagari, CJK numerals (`三`→`四`) — and the digit stays
in its own script. Kings, Samuel, Chronicles, Esdras and Maccabees are excluded
because 3–4 Kings and 4 Maccabees are real books in some canons, and a "fake" book
some tradition actually has is not a hallucination probe. The constructed name is
checked against the edition's own book list before it is used.

This took non-canonical coverage from **1 language to 9**. Russian
("Второе послание к Коринфянам") and Arabic ("كُورِنْثُوسَ ٱلثَّانِيةُ") spell the number
as a **word**, which cannot be bumped mechanically, so those editions get
out-of-range references only until a native speaker supplies the ordinal form —
tracked in `docs/TODO_BEFORE_RELEASE.md`. The line is deliberate: a numeral is
script and can be transformed; a number-word is vocabulary and cannot be guessed.

## What stays uneven, on purpose

`absent_from_version` asks a named edition for a book its canon lacks (Sirach from
the NIV). A wider-canon edition legitimately has fewer of these, and an edition
with no sibling to compare against has none — for the NABRE, Sirach is not an
impossible reference. That variation is the probe working. It is derived by
comparing two editions' book lists; nothing in the codebase knows what
"deuterocanonical" means.

## Expect scores to move

The dimension went from one easy reference kind to four, so hallucination charges
should grow. A v0.5 hallucination score is **not** comparable to a v0.6 one, which
is why this is a version bump rather than a re-score — and a re-score could not
produce it in any case, since `score` reads the item list out of the stored
manifest and these are different prompts.

## Scoring, tracks and languages

Unchanged from v0.5: the −100…+100 ledger, Quoting Accuracy (0…+100) plus
Hallucination (−100…0), the same 168-reference draw over 18 editions in 11
languages, and the Nicene Creed pair reported separately as an internal beta.
